How it works

No tech skills needed. It takes about two minutes.

  1. Unzip your download. Inside you’ll find the skill file and its own install guide with sample prompts.
  2. Add it to Claude. Open claude.ai, click Customize, then Skills. Click +, then Create skill, then Upload a skill. Pick the file and make sure its toggle is on.
  3. Try it. Start a new chat and paste the first sample prompt from your guide. Swap in your own details and go.

You’ll need: a Claude.ai account with Code execution turned on in Settings → Capabilities. Skills need this switch.
